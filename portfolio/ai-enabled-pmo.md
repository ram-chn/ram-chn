# Case Study: AI-Enabled Program Management Workflows

**Domain:** Internal program operations and reporting  
**Focus:** Requirements visibility, workflow automation, LLM-assisted insights  
**Role:** Program leader and hands-on workflow builder

## Problem

Program teams needed a more efficient way to find requirement information, understand execution signals, and prepare consistent status updates across many engineering workstreams. Manual lookup and fragmented reporting slowed coordination.

## Approach

- Designed an internal lightweight program-management application using **Google Apps Script** and structured program data.
- Integrated **Jira APIs** to retrieve relevant fields and activity for program visibility.
- Experimented with **approved internal LLM services** to support natural-language lookup and analysis of delivery signals.
- Created repeatable views for requirements, capacity considerations, risks, and stakeholder reporting.
- Used controlled reviews and versioned development practices to reduce the risk of accidental changes.

## Scope and contribution

The workflow supported program visibility across approximately **20 teams**. My contribution spanned program requirements, workflow design, hands-on automation, stakeholder input, and governance.

## What this demonstrates

Technical curiosity, pragmatic automation, cross-team process design, API integration literacy, and the ability to connect AI tools with real delivery needs.
